## Featured Architectures

### [StreamShield](https://github.com/raghavatgit/StreamShield)
* **Stack:** Rust, Tauri, Windows API, React, TypeScript
* Per-app stream privacy manager for Windows.
* Operates at the operating system level to exclude selected desktop application windows from screen capture feeds (OBS Studio, Discord, Medal) in real time without disrupting local monitor display.
* Zero perceived latency using a lightweight dynamic link library and sub-30 MB memory consumption.

### [ContactMe](https://github.com/raghavatgit/ContactMe)
* **Stack:** Vanilla JavaScript, CSS3 3D Transforms, Firebase Hosting
* Interactive 3D spatial web portal.
* Calculates real-time cursor trajectory and velocity to apply perspective matrices, dynamic lighting shaders, and tactile spring physics without third-party graphics engines.
* Live demo: [contactraghav.web.app](https://contactraghav.web.app)

### [Zenflow-3D](https://github.com/raghavatgit/Zenflow-3D)
* **Stack:** JavaScript, CSS3 Spatial Hierarchies
* Kinetic spatial interface and deep work dashboard prototype showcased at the ACM Tech Symposium.
* Implements multi-layered CSS perspective planes and card hover physics for distraction-free task management.
